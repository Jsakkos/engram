    Non-English Content Implementation Plan

    For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

    Goal: Stop silently mis-matching TV tracks whose dialogue is not English: transcribe the right audio stream, park unmatchable tracks in review with a reason that names the language (phase 1), then match non-English shows in their own language (phase 2).

    Architecture: One language-code module; scan-time SINFO capture stored on DiscTitle as evidence; a per-file ffprobe "audio plan" owned by EpisodeMatcher that picks the stream (-map 0:a:<n>) and returns a verdict; the curator refuses ASR on a foreign verdict after the chromaprint prepass, and the coordinator/finalizer treat that refusal like the existing references_unreadable one.

    Tech Stack: Python 3.11, FastAPI, SQLModel + Alembic, ffmpeg/ffprobe, faster-whisper, scikit-learn; React 19 + vitest.

    Spec: docs/superpowers/specs/2026-10-20-non-english-content-design.md

    Global Constraints

    • Phase 1 PR says "Refs #241"; phase 2 says "Fixes #241".
    • Any probe that cannot decide (ffprobe missing, error, untagged streams, unknown codes) yields today's behaviour. The only new no-ASR outcome is verdict foreign (and no_audio).
    • Review error code string: audio_language_unsupported.
    • Normalized language form: ISO 639-1 where the table maps it, else the lower-case three-letter code; "", und, mis, mul, zxx, qaa..qtz normalize to None.
    • No new Python dependency (frozen-build hidden-import risk).
    • New DiscTitle columns are nullable; Alembic revision plus nothing else (_add_missing_columns() covers frozen builds). Check uv run alembic heads for the current head before writing down_revision.
    • Do not change _build_markdown_summary's report.md format (the Discord bot parses it).
    • Never touch MakeMKV settings.conf beyond what exists.
    • Real ~/.engram/cache stays read-only; tests use tmp dirs.
    • CHANGELOG [Unreleased] entry credits the contributor: (thanks @wintheriscomming!).
    • No em dashes in prose (code comments, CHANGELOG, PR text).
    • Backend from backend/: uv run pytest, uv run ruff check ., uv run ruff format .. Frontend from frontend/: npm run test:unit, npm run lint, npm run build.

    Review Focus

    1. A disc whose every episode-length title is foreign. Expect review with the language reason, not _detect_wrong_show naming a same-name twin and not a cross-season re-run. Test in Task 7.
    2. An English disc with a foreign dub flagged default (ffmpeg would have picked the dub). Expect the English stream to be mapped. Test in Task 5.
    3. Previously cached transcripts of English discs. Expect stream 0 to keep today's L2 transcript key so existing caches still hit. Test in Task 5.
    4. ffprobe missing or failing. Expect verdict unprobed, no -map, ASR proceeds exactly as today. Tests in Tasks 4 and 6.
    5. Auto-escalation (deep re-match) over a language-parked title. Expect match_details kept and no re-dispatch. Test in Task 7.
